# Sistema de Nómina

Aplicación desarrollada en Java cuyo propósito es calcular la nómina mensual de los empleados y guardar los resultados en una base de datos local. El módulo se enfoca exclusivamente en dos responsabilidades: calcular nóminas y almacenar los cálculos realizados.

## Stack Tecnológico & Criterios de Calidad

* **Lenguaje Principal:** Java (
* **Arquitectura:** Diseño por capas y principios SOLID
* **Persistencia:** Base de datos local integrada
* **Calidad de Código:** Desarrollo guiado por pruebas (TDD) enfocado en la lógica del dominio

##  Funcionalidades Clave

* **Cálculo Polimórfico:** Procesamiento automatizado de salarios según el tipo de vinculación (Asalariados, Horas, Comisión y Temporales).
* **Gestión de Deducciones:** Aplicación automática de retenciones legales (Seguridad Social/Pensión) y beneficios empresariales.
* **Persistencia Segura:** Validaciones estrictas antes del almacenamiento (bloqueo de salarios netos negativos y valores de control no negativos).

##  Requisitos Previos

Antes de compilar el proyecto, asegúrate de contar con:
* Un entorno de desarrollo compatible con Java (como IntelliJ IDEA)
* Java Development Kit (JDK) instalado
* Controlador/driver de la base de datos local seleccionada

##  Ejecución

El sistema se opera de forma exclusiva a través de la **interfaz de línea de comandos (CLI) o terminal**.
